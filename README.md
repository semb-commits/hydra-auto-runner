# hydra-auto-runner

Bash script interaktif buat jalanin Hydra lebih cepat.  
Dibuat untuk edukasi dan authorized security testing saja.

## Features
- Input interaktif, gak perlu hapal command panjang
- Support SSH, FTP, HTTP-Post-Form, HTTP-Get-Form
- Validasi wordlist otomatis
- Output warna biar gampang dibaca

## Installation
```bash
git clone https://github.com/semb-commits/hydra-auto-runner.git
cd hydra-auto-runner
chmod +x hydra-run.sh
